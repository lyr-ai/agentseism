# Controlled perturbation (Week 4)

Empty on purpose. Perturbations enter only after natural variation (Week 1-2)
has shown there is a phenomenon to explain (DESIGN.md §16).

Planned scope: **two** transformations, no catalogue.

- `paraphrase` — semantically equivalent rewording of the task input
- `context_order` — reordering of independent context items

Each answers the same question: where does a known small input variation get
amplified inside the execution?
