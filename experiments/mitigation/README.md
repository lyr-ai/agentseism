Take the top-ranked weak points, mitigate them by hand, and measure on held-out
tasks (DESIGN.md §25, RQ4):

```text
behavioral variation   before / after
task quality           before / after
cost                   before / after
latency                before / after
```

A mitigation that reduces variation while degrading quality is a negative
result and must be reported as one.
